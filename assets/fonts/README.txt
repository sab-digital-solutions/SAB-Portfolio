"The Seasons" is a licensed display font (not free/open-source), so it can't
be bundled in this project automatically. To make the large headlines render
in The Seasons, buy/download your license and drop the web font files here
using these exact names:

  TheSeasons-Regular.woff2   (preferred — smallest file)
  TheSeasons-Regular.woff    (fallback for older browsers)
  TheSeasons-Regular.otf     (optional extra fallback)

style.css already declares the @font-face and applies "The Seasons" to the
big headline / statement text (see "The Seasons" in style.css, section 1).
Until the files are added here, those headings simply fall back to the
existing Bodoni Moda display font, so the site still looks complete.
